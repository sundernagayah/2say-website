## Replace later
### Logo
In `index.html`, replace the text `2SAY` inside the `.brand` link with an `<img>` element when you have your logo.

### Showreel
Replace the showreel button `href="#work"` with your Vimeo/YouTube URL or a dedicated showreel page.

### Stills
In `styles.css`, replace the placeholder image URLs used by:
- `.hero::after`
- `.img-1`
- `.img-2`
- `.img-3`
- `.img-4`
- `.about-image`
- `.contact-banner`

For best performance, use local `.webp` or optimized `.jpg` files inside an `/assets` folder.

### Social links
Replace the `href="#"` values for Instagram, YouTube, Vimeo and LinkedIn.

## Publish
Recommended free stack:
- GitHub → source files
- Cloudflare Pages → hosting
- `2sayfilms.com` → custom domain
- Google Workspace → email

Do not remove Google Workspace MX records when connecting the website domain.
